# 🎙️ مَشـرُوع «صَـدَى» (Sada)
### مشغل التلاوات القرآنية الخام مع إضافة المؤثرات الصوتية آنيًا (Web Audio DSP Player)

موقع ويب تفاعلي يعمل بالكامل على المتصفح **(100% Client-Side Serverless)** دون الحاجة إلى أي سيرفر أو خادم خلفي. يُمكن استضافته وتشغيله مباشرة عبر **GitHub Pages** أو أي استضافة للملفات الثابتة.

---

## ✨ المميزات الرئيسية

1. **معالجة صوتية حقيقية آنية (Real-Time Web Audio DSP)**:
   - **صدى حقيقي (Convolution Reverb)** مبني بدوال Impulse Response هندسية تحاكي الصدى الصوتي الواقعي في المساجد الكبرى والاستوديوهات الاحترافية.
   - **تردد وتكرار استيريو (Stereo Delay & Echo)** بزمن وتكرار قابلين للضبط بدقة.
   - **معادل نغمات ثلاثي (3-Band Parametric EQ)** للتحكم في عمق الصوت (Bass)، ووضوح الكلمات ومخارج الحروف (Mid)، وبريق التلاوة ونقاء النفس (Treble).

2. **بيئات صوتية جاهزة (Acoustic Presets)**:
   - 🕋 **الحرم المكي الشريف**: فضاء رحب مع صدى مهيب هادئ.
   - 🕌 **المسجد النبوي الشريف**: صفاء نغمي، خالي من الطنين المزعج.
   - 🏛️ **جامع حديث واسع**: ارتداد متوازن يبرز جمال الصوت.
   - 🎙️ **استوديو ذهبي نقي**: معالجة صوتية هادئة تحاكي تسجيلات الإذاعة.
   - ⚪ **الصوت الخام (Bypass)**: الاستماع للتسجيل الأصلي مباشرة دون أي مؤثرات.

3. **مقارنة فورية (A/B Instant Comparison)**:
   - زر التبديل السريع للمقارنة اللحظية بين الصوت مع المؤثرات (Wet) وبدونها (Dry) للتحقق من جودة وجمال المعالجة.

4. **تصدير التسجيل مع المؤثرات بصيغة WAV**:
   - محرك `OfflineAudioContext` يقوم بريندر عالي السرعة (خلال ثوانٍ معدودة) وتنزيل الملف الصوتي مدمجاً بالمؤثرات التي اخترتها بدقة الاستوديو.

5. **سحب وإفلات الملفات (Drag & Drop)**:
   - إمكانية سحب أي ملف صوتي خام من حاسوبك (MP3, WAV, M4A, OGG) ومعالجته والاستماع إليه فورياً وحفظه مع المؤثرات.

6. **تلاوات خام مضمنة**:
   - يحتوي المشروع محلياً على تلاوات كاملة مسجلة خام في الاستوديو بدون أي مؤثرات للشيخ **بدر التركي** (الفاتحة، الإخلاص، الفلق، الناس) من إنتاج المركز السعودي للتلاوات القرآنية.

## 🚀 طريقة النشر والتشغيل على GitHub Pages (في 3 خطوات)

المشروع مصمم ليعمل مباشرة كصفحة ثابتة بدون Node.js:

### 1. إنشاء مستودع جديد على حسابك في GitHub
- ادخل على GitHub وأنشئ مستودعاً جديداً باسم (مثلاً: `sada` أو `sada-quran-player`).

### 2. رفع الملفات إلى المستودع
في مجلد المشروع على جهازك، نفّذ الأوامر التالية في الطرفية (Terminal / PowerShell):

```bash
# تهيئة المستودع
git init

# إضافة جميع الملفات
git add .

# إنشاء أول Commit
git commit -m "Initial commit: Sada Web Audio DSP Player"

# ربط المستودع برابط مستودعك على غيت هب
git remote add origin https://github.com/USERNAME/REPO_NAME.git

# رفع الكود
git branch -M main
git push -u origin main
```

*(استبدل `USERNAME` و `REPO_NAME` باسم حسابك واسم المستودع).*

### 3. تفعيل GitHub Pages
1. ادخل على إعدادات مستودعك على GitHub: **Settings**
2. من القائمة الجانبية اختر: **Pages**
3. تحت قسم **Build and deployment**:
   - اختر **Source**: `Deploy from a branch`
   - اختر **Branch**: `main` واختر المجلد `/ (root)`
   - اضغط **Save**

🎉 **خلال دقيقة واحدة سيكون موقعك متاحاً ويعمل على الرابط:**
```
https://<USERNAME>.github.io/<REPO_NAME>/
```

## 💻 التشغيل المحلي (اختياري)

إذا أردت تجربة المشروع محلياً على حاسوبك:

- **الخيار الأول (مباشر عبر أي خادم ويب ثابت)**:
  يمكنك فتح المجلد عبر إضافة **Live Server** في VS Code أو نقله إلى مجلد `laragon/www`.
  
- **الخيار الثاني (عبر Node.js)**:
  ```bash
  node server.js
  ```
  ثم افتح المتصفح على: `http://localhost:3000`
